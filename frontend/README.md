# Frontend Module

React client for the Dish Management System.

## Scripts

From this directory:

```bash
npm install
npm start
```

Available commands:

- `npm start` — Start development server (`http://localhost:3000`)
- `npm test` — Run test watcher
- `npm run build` — Build for production

## Notes

- Built on Create React App
- Uses React Router, Axios, and React DnD
- See the repository root `README.md` for full-stack setup and architecture
